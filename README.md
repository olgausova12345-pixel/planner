# Планировщик

Личное веб-приложение (PWA) для телефона Xiaomi: план дел на день/неделю/месяц, покупки по датам, заметки с папками, дни рождения. Работает без интернета, записи хранятся только на телефоне.

Чистые HTML, CSS и JavaScript (ES-модули), без сборки и без внешних запросов.

## Состав

| Файл | Что внутри |
| --- | --- |
| `index.html` | Все разделы и диалоги, SVG-спрайт иконок, CSP |
| `boot.js` | Тема и размер текста до первой отрисовки (без мигания) |
| `styles.css` | Токены цвета, светлая и тёмная темы, раскладки narrow / wide (по ширине в rem) |
| `logic.js` | Чистые функции: даты, повторы, перенос, просрочка, напоминания, производственный календарь РТ, ДР, разбор копии |
| `app.js` | Интерфейс: план, покупки, заметки, меню, копии, напоминания, установка, обновления |
| `birthdays.js` | Раздел «ДР», фабрика `createBirthdays(ctx)` |
| `db.js` | IndexedDB `planner` v5, миграции только добавляют; запасной режим «в памяти» |
| `sw.js` | Service Worker: офлайн-кэш оболочки по версии, обновление по кнопке |
| `manifest.webmanifest`, `icons/` | Установка на главный экран, иконки 192/512 + maskable |
| `version.json` | Строка версии (показывается в меню) |
| `_headers` | Заголовки Netlify: CSP, no-cache для `sw.js` и `index.html` |
| `fonts/` | Сюда положить `golos-text-500.woff2` и `golos-text-700.woff2` (см. `fonts/README.txt`) |
| `tests/` | Автотесты логики (`node:test`) и сквозные тесты Playwright |

## Тесты

```sh
npm test                         # логика: даты, повторы, перенос, просрочка, напоминания, копия, ДР 29.02, календарь РТ
pip install playwright && playwright install chromium
python3 tests/e2e.py             # сквозные: 360 и 412 px, вертикально и горизонтально, тёмная тема, 150%, авиарежим
python3 tests/e2e.py --shots out # то же + снимки экранов в папку out
```

Для проверки поведения в другое время суток можно открыть приложение с параметром `?now=2026-10-29T20:30:00`.

## Выпуск новой версии

1. Внесите изменения.
2. Поменяйте строку версии сразу во всех файлах: `sh scripts/release.sh 2026.11.05-1` (меняет `version.json`, `sw.js` и `?v=` в `index.html`).
3. Прогоните `npm test` и `python3 tests/e2e.py`.
4. Перетащите папку проекта в Netlify (Deploys → «Drag and drop your project folder»). Сборка не нужна.
5. На телефоне при следующем открытии появится баннер «Доступна новая версия. Ваши записи сохранятся» → «Обновить».

## Установка на телефон Xiaomi

1. Откройте адрес сайта **в Chrome** (если ссылка открылась в браузере Xiaomi — нажмите в приложении «Открыть в Chrome»). Записи в двух браузерах хранятся отдельно — выберите Chrome до первых записей.
2. Нажмите «Установить» в баннере или в шапке (или ⋮ → «Установить приложение»).
3. Если значок не появился на рабочем столе: Настройки → Приложения → Все приложения → Chrome → Другие разрешения → «Ярлыки на рабочем столе» → включить, затем повторить установку.
4. Для напоминаний: разрешите уведомления Chrome (Настройки → Уведомления → Chrome), включите «Всплывающие уведомления»; в «Контроле активности» Chrome выберите «Нет ограничений». Напоминания работают, пока приложение открыто.
5. После первых записей сохраните резервную копию себе в мессенджер: Меню → «Сохранить копию».

## Изменения относительно эталона v9 (сборка 2026.10.29-dr19)

- Удалён раздел «Цикл»: экран, пункт навигации, `cycle.js`, хранилище `cycle`, код-пароль, метки в календаре, напоминания, данные цикла в копиях. Старое хранилище `cycle` в базе не трогается (данные не удаляются), но и не используется.
- Удалены типовые папки «Фильмы» и «Рецепты» и особые поля заметок. Папки создаёт пользователь, все одинаковые. Поля фильмов/рецептов из старых копий превращаются в обычный текст заметки.
- «Все» — вид по умолчанию: заметки вне папок (и со ссылкой на удалённую папку); поиск из «Все» ищет и в папках.
- Удалены синхронизация, облако (`cloud.js`, `cloud-config.js`, Firebase), вход через Google, QR-код «Открыть на телефоне» (`vendor/qrcode.js`), слияние записей (`mergeSync`). Служебные поля `_mt`, `deleted`, `device` в копиях молча пропускаются.
- Только телефонные раскладки: `narrow` (вертикально) и `wide` (горизонтально); раскладка `xl` убрана. Ширина считается в rem, поэтому крупный текст не ломает вёрстку.
- Поля даты — свой русский мини-календарь вместо системного (одинаково выглядит в Chrome и браузере Xiaomi).
- Добавлены подсказки для Xiaomi: «Открыть в Chrome», разрешение «Ярлыки на рабочем столе», уведомления и энергосбережение, «Очистка» в приложении «Безопасность».
- Резервная копия предлагается сразу после первых записей, затем — раз в 30 дней.
- Производственный календарь Республики Татарстан на 2026–2027 годы (таблица `PROD_CALENDAR` в `logic.js`). Национальные праздники 2027: Ураза-байрам 9 марта, Курбан-байрам 16 мая, День Республики 30 августа, День Конституции РТ 6 ноября.


## Android-приложение (напоминания при закрытом приложении)

Тот же код упаковывается в Android-приложение через Capacitor. В нём напоминания ставятся на системный будильник Android
(`native.js`, плагин Local Notifications) и приходят со звуком и всплывающим окном, даже когда приложение закрыто,
без интернета и без сервера. На сайте `native.js` ничего не делает.

- Сборка — автоматически на GitHub (`.github/workflows/android.yml`) при каждом изменении в ветке `main`.
- Готовый файл: вкладка Releases, ссылка на последнюю версию — `releases/latest/download/planner.apk`.
- Подпись: секреты репозитория `KEYSTORE_B64` и `KEYSTORE_PASSWORD`. Ключ нельзя терять — без него новую версию
  нельзя будет поставить поверх старой.
- Проверка Android-логики без телефона: `python3 tests/native_sim.py` и `python3 tests/app_update_sim.py`.
- Обновление из приложения: раз в день (и по кнопке в Меню) приложение спрашивает у GitHub номер последнего релиза
  (`releases/latest`). Если он новее установленного, показывается баннер «Обновить»: APK скачивается и открывается
  установщик Android. Отправляется только этот запрос, записи никуда не уходят. Android ставит обновление, только если
  оно подписано тем же ключом.

Первая установка на Xiaomi: открыть `planner.apk` → разрешить установку из этого источника → «Установить».
Затем в приложении: разрешить уведомления; долгое нажатие на значок → «О приложении» → «Автозапуск» включить,
«Контроль активности» → «Нет ограничений». Записи с сайта переносятся через резервную копию: на сайте
«Сохранить копию», в приложении «Восстановить из файла».
