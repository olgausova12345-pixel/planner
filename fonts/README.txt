Положите сюда два файла шрифта Golos Text (лицензия SIL OFL, бесплатный):
  golos-text-500.woff2  — начертание Medium (500), кириллица + латиница
  golos-text-700.woff2  — начертание Bold (700), кириллица + латиница
Скачать: https://fonts.google.com/specimen/Golos+Text (или пакет @fontsource/golos-text, файлы
golos-text-cyrillic-500-normal.woff2 и ...-700-normal.woff2 — переименовать).
Пока файлов нет, приложение использует системный шрифт телефона (Roboto / MiSans) — всё работает.
